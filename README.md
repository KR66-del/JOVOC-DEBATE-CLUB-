# 🚀 Publishing on GitHub

1. Create a GitHub repository.

2. Upload all project files.

3. Go to

Settings → Pages

4. Choose

Deploy from Branch

5. Select

main

6. Save.

Your website will be live at

```
https://YOUR_USERNAME.github.io/REPOSITORY-NAME/
```
